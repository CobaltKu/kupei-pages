# 給後端的需求與建議

要改後端（API、資料格式、權杖、帳號、行情、批次發布…）或發現後端程式的問題，**一律寫在這裡**。
後端窗口每次同步時會把新項目搬進後端的總表處理，並把回覆寫回「回覆」欄。

- 一列一件事；不確定就先寫，標「詢問」。
- 不要貼權杖、密碼、邀請碼或任何憑證。
- 很急的同時私訊告知。
